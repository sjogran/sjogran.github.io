Privacy policy

Family School Calendar is a personal tool used by one family on one home computer. This page explains what it does with Google data.

What it accesses

  • Google Calendar events only (the calendar.events permission), on the one calendar the family member chose to connect.
  • It lists events on that calendar to avoid adding duplicates, adds the events the user ticked, and updates or removes only events it added itself.
  • It does not access email, contacts, files or any other Google data.

Where data is kept

  • The sign-in token is stored in the home computer's system keychain, and nowhere else.
  • Calendar data is used only to make these changes. It is not sold, shared, sent to any other service, or used for advertising.
  • The tool has no servers on the internet and no other users.

Removing access

Access can be removed at any time from the Google Account's Third-party apps & services page.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
